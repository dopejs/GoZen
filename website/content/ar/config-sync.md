# مزامنة الإعدادات

زامن المزوّدين وملفات التعريف وملف التعريف الافتراضي والعميل الافتراضي بين الأجهزة. وتُشفَّر رموز المصادقة بخوارزمية AES-256-GCM (اشتقاق المفتاح بـ PBKDF2-SHA256) قبل الرفع.

## الخدمات المدعومة

| الخدمة | الوصف |
|--------|-------|
| `webdav` | أي خادم WebDAV (مثل Nextcloud و ownCloud) |
| `s3` | ‏AWS S3 أو تخزين متوافق معه (مثل MinIO و Cloudflare R2) |
| `gist` | ‏gist خاص (يتطلب رمز PAT بصلاحية gist) |
| `repo` | ملف في مستودع عبر واجهة Contents (يتطلب رمز PAT بصلاحية repo) |

## الإعداد

اضبط المزامنة من صفحة الإعدادات في واجهة الويب:

```bash
# فتح إعدادات واجهة الويب
zen web  # الإعدادات ← مزامنة الإعدادات
```

أو اسحب الإعدادات يدويًا من سطر الأوامر:

```bash
zen config sync
```

## مثال على الإعداد

```json
{
  "sync": {
    "backend": "gist",
    "gist_id": "abc123def456",
    "token": "ghp_xxxxxxxxxxxx",
    "passphrase": "my-secret-passphrase",
    "auto_pull": true,
    "pull_interval": 300
  }
}
```

## التشفير

عند ضبط عبارة مرور، تُشفَّر كل رموز المصادقة في حمولة المزامنة بـ AES-256-GCM بمفتاح مشتق عبر PBKDF2-SHA256 (‏600 ألف تكرار). ويُخزَّن الملح إلى جانب الحمولة. وبدون عبارة مرور تُرفع البيانات بصيغة JSON غير مشفّرة.

## حل التعارضات

- دمج بحسب الطابع الزمني لكل كيان: يفوز التعديل الأحدث
- الكيانات المحذوفة تستخدم علامات حذف (تنتهي بعد 30 يومًا)
- القيم المفردة (ملف التعريف/العميل الافتراضي): يفوز الطابع الزمني الأحدث

## نطاق المزامنة

**يُزامَن:** المزوّدون (برموز مشفّرة)، وملفات التعريف، وملف التعريف الافتراضي، والعميل الافتراضي

**لا يُزامَن:** إعدادات المنافذ، وكلمة مرور واجهة الويب، وارتباطات المشاريع، وإعدادات المزامنة نفسها
