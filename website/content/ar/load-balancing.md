# موازنة الأحمال

إضافةً إلى التحويل البسيط عند الفشل، يدعم GoZen عدة استراتيجيات لاختيار المزوّد. يمكنك اختيار استراتيجية لكل ملف تعريف، ودمجها مع فحوص السلامة، وتوجيه حركة الطلبات وفق التوفّر أو الكمون أو التكلفة.

## الاستراتيجيات المتاحة

### التحويل عند الفشل

يجرّب المزوّدين بالترتيب حتى ينجح أحدهم. وهي الاستراتيجية الافتراضية، وتناسب إعداد مزوّد أساسي وآخر احتياطي.

```json
{
  "profiles": {
    "default": {
      "providers": ["primary", "backup"],
      "strategy": "failover"
    }
  }
}
```

### التناوب الدوري

يوزّع الطلبات بالتساوي على عدة مزوّدين متكافئين.

```json
{
  "profiles": {
    "balanced": {
      "providers": ["provider-a", "provider-b", "provider-c"],
      "strategy": "round-robin"
    }
  }
}
```

### أقل كمون

يفضّل المزوّد صاحب أقل زمن استجابة حديث.

```json
{
  "profiles": {
    "fast": {
      "providers": ["us-east", "us-west", "eu"],
      "strategy": "least-latency"
    }
  }
}
```

### أقل تكلفة

يفضّل المزوّد الأرخص للنموذج المطلوب.

```json
{
  "profiles": {
    "budget": {
      "providers": ["cheap-provider", "premium-provider"],
      "strategy": "least-cost"
    }
  }
}
```

## توجيه يراعي السلامة

تعمل كل الاستراتيجيات مع مراقبة السلامة. وعند تفعيل `health_aware` يُتخطّى المزوّدون غير السليمين تلقائيًا حتى يتعافوا.

```json
{
  "profiles": {
    "production": {
      "providers": ["primary", "secondary", "tertiary"],
      "strategy": "least-latency",
      "health_aware": true
    }
  }
}
```

## كيف تختار استراتيجية

- استخدم `failover` حين تكون الموثوقية هي الأولوية.
- استخدم `round-robin` حين يكون المزوّدون متكافئين.
- استخدم `least-latency` للأحمال التفاعلية أو الحساسة للوقت.
- استخدم `least-cost` حين تكون الميزانية أهم من السرعة.

## مستندات ذات صلة

- [ملفات التعريف](/docs/profiles) تشرح كيفية تعريف مجموعات المزوّدين.
- [التوجيه](/docs/routing) يتناول اختيار المزوّد حسب السيناريو.
- [مراقبة السلامة](/docs/health-monitoring) تشرح أثر فحوص السلامة على التوجيه.
