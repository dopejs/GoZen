# واجهة الويب

أدر جميع الإعدادات بصريًا من المتصفح. وتبدأ الخدمة تلقائيًا عند الحاجة.

## الاستخدام

```bash
# الفتح في المتصفح (يشغّل الخدمة عند الحاجة)
zen web
```

## المزايا

- إدارة المزوّدين وملفات التعريف
- إدارة ارتباطات المشاريع
- الإعدادات العامة (العميل الافتراضي، ملف التعريف الافتراضي، المنافذ)
- إعدادات مزامنة الإعدادات
- عارض سجل الطلبات مع تحديث تلقائي
- إكمال تلقائي لحقل النموذج

## الأمان

عند أول تشغيل للخدمة تُولَّد كلمة مرور للوصول تلقائيًا. وتتطلب الطلبات غير المحلية (خارج 127.0.0.1/::1) تسجيل الدخول.

- مصادقة قائمة على الجلسات مع مدة صلاحية قابلة للضبط
- حماية من التخمين المتكرر بتأخير متزايد أُسّيًا
- تشفير RSA لنقل الرموز الحساسة (تُشفَّر مفاتيح API داخل المتصفح)
- الوصول المحلي (127.0.0.1) يتجاوز المصادقة

### إدارة كلمة المرور

```bash
# إعادة تعيين كلمة مرور واجهة الويب
zen config reset-password

# تغيير كلمة المرور من واجهة الويب
zen web  # الإعدادات ← تغيير كلمة المرور
```
