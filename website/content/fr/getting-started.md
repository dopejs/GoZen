# Démarrage

## Installation

Installez avec le script en une ligne :

```bash
curl -fsSL https://raw.githubusercontent.com/dopejs/gozen/main/install.sh | sh
```

Désinstallation :

```bash
curl -fsSL https://raw.githubusercontent.com/dopejs/gozen/main/uninstall.sh | sh
```

## Première utilisation

Ajoutez votre premier fournisseur :

```bash
zen config add provider
```

Démarrez avec le profil par défaut :

```bash
zen
```

Démarrez avec un profil précis :

```bash
zen -p work
```

Démarrez avec une CLI précise :

```bash
zen --cli codex
```
