# דחיסת הקשר (בטא)

:::warning יכולת בבטא
דחיסת ההקשר נמצאת בשלב בטא. היא כבויה כברירת מחדל ודורשת הגדרה מפורשת כדי לפעול.
:::

דוחסת אוטומטית את הקשר השיחה כשמספר האסימונים חורג מהסף, וכך מפחיתה עלויות תוך שמירה על איכות השיחה.

## יכולות

- **דחיסה אוטומטית** — מופעלת כשמספר האסימונים חורג מהסף
- **סיכום חכם** — מודל זול (claude-3-haiku) מסכם הודעות ישנות
- **שמירת הודעות אחרונות** — ההודעות האחרונות נשארות שלמות לשמירת רצף
- **הערכת אסימונים** — ספירה מדויקת לפני קריאות ל-API
- **מעקב סטטיסטי** — בדקו עד כמה הדחיסה יעילה
- **פעולה שקופה** — עובד עם כל לקוחות ה-AI

## איך זה עובד

1. **הערכת אסימונים** — ספירת אסימונים בהיסטוריית השיחה
2. **בדיקת סף** — השוואה לסף שהוגדר (ברירת מחדל: 50,000)
3. **בחירת הודעות** — זיהוי ההודעות הישנות לדחיסה
4. **סיכום** — יצירת סיכום תמציתי במודל זול
5. **החלפת ההקשר** — ההודעות הישנות מוחלפות בסיכום
6. **העברת הבקשה** — ההקשר הדחוס נשלח למודל היעד

## הגדרה

### הפעלת הדחיסה

```json
{
  "compression": {
    "enabled": true,
    "threshold_tokens": 50000,
    "target_tokens": 20000,
    "summarizer_model": "claude-3-haiku-20240307",
    "preserve_recent_messages": 5,
    "tokens_per_char": 0.25
  }
}
```

**אפשרויות:**

| אפשרות | ברירת מחדל | תיאור |
|--------|---------|-------------|
| `enabled` | `false` | מפעיל את דחיסת ההקשר |
| `threshold_tokens` | `50000` | מפעיל דחיסה כשההקשר חורג מערך זה |
| `target_tokens` | `20000` | מספר האסימונים הרצוי לאחר הדחיסה |
| `summarizer_model` | `claude-3-haiku-20240307` | המודל המשמש לסיכום |
| `preserve_recent_messages` | `5` | כמה הודעות אחרונות יישארו שלמות |
| `tokens_per_char` | `0.25` | יחס ההערכה לספירת אסימונים |

### הגדרה לכל פרופיל

הפעילו דחיסה עבור פרופילים מסוימים:

```json
{
  "profiles": {
    "long-context": {
      "providers": ["anthropic"],
      "compression": {
        "enabled": true,
        "threshold_tokens": 100000,
        "target_tokens": 40000
      }
    },
    "short-context": {
      "providers": ["openai"],
      "compression": {
        "enabled": false
      }
    }
  }
}
```

## הערכת אסימונים

‏GoZen מעריך אסימונים במהירות לפי מספר התווים:

```
estimated_tokens = character_count * tokens_per_char
```

**יחס ברירת המחדל:** 0.25 אסימונים לתו (אסימון אחד ≈ 4 תווים)

**דיוק:** ±10% לטקסט באנגלית, ועשוי להשתנות בשפות אחרות

לספירה מדויקת GoZen משתמש בספריית `tiktoken-go` כשהיא זמינה.

## אסטרטגיית הדחיסה

### בחירת הודעות

1. **הודעות מערכת** — נשמרות תמיד
2. **הודעות אחרונות** — N ההודעות האחרונות נשמרות (ברירת מחדל: 5)
3. **הודעות ישנות יותר** — מועמדות לדחיסה

### הנחיית הסיכום

```
Summarize the following conversation history concisely while preserving key information, decisions, and context:

[older messages]

Provide a brief summary that captures the essential points.
```

### התוצאה

```
Original: 45,000 tokens (30 messages)
After compression: 22,000 tokens (summary + 5 recent messages)
Savings: 23,000 tokens (51%)
```

## ממשק ווב

הגדרות הדחיסה נמצאות בכתובת `http://localhost:19840/settings`:

1. עברו ללשונית "Compression" (מסומנת בתג BETA)
2. הפעילו את "Enable Compression"
3. כווננו את הסף ואת מספר האסימונים הרצוי
4. בחרו את מודל הסיכום
5. קבעו כמה הודעות אחרונות יישמרו
6. לחצו על "Save"

### לוח סטטיסטיקה

צפו בנתוני הדחיסה:

- **סך הדחיסות** — כמה פעמים הופעלה דחיסה
- **אסימונים שנחסכו** — סך האסימונים שנחסכו
- **חיסכון ממוצע** — הפחתת אסימונים ממוצעת לכל דחיסה
- **שיעור דחיסה** — אחוז הבקשות שהפעילו דחיסה

## נקודות קצה ב-API

### קבלת נתוני דחיסה

```bash
GET /api/v1/compression/stats
```

תגובה:
```json
{
  "enabled": true,
  "total_compressions": 42,
  "tokens_saved": 1250000,
  "average_savings": 29761,
  "compression_rate": 0.15,
  "last_compression": "2026-03-05T10:30:00Z"
}
```

### עדכון הגדרות הדחיסה

```bash
PUT /api/v1/compression/settings
Content-Type: application/json

{
  "enabled": true,
  "threshold_tokens": 60000,
  "target_tokens": 25000
}
```

### איפוס הסטטיסטיקה

```bash
POST /api/v1/compression/stats/reset
```

## המלצות

1. **התחילו מברירות המחדל** — הן מתאימות לרוב המקרים
2. **עקבו אחרי הסטטיסטיקה** — בדקו בקביעות את שיעור הדחיסה והחיסכון
3. **כווננו את הסף** — העלו אותו למודלים עם הקשר ארוך (Claude Opus), הורידו למודלים קצרים
4. **שמרו מספיק הודעות** — 5–10 הודעות אחרונות לשמירת רצף
5. **בחרו מודל סיכום זול** — Haiku מהיר וחסכוני
6. **בדקו לפני ייצור** — ודאו את איכות הדחיסה בתרחיש שלכם

## מגבלות

1. **אובדן איכות** — הסיכום עלול לאבד ניואנסים
2. **עלייה בהשהיה** — נוספת קריאת API לסיכום
3. **שיקול עלות** — עלות הסיכום מול האסימונים שנחסכו
4. **תמיכה בשפות** — עובד הכי טוב באנגלית, ועשוי להשתנות בשפות אחרות
5. **חלון ההקשר** — אי אפשר לחרוג מחלון ההקשר המרבי של המודל

## פתרון תקלות

### הדחיסה אינה מופעלת

1. ודאו ש-`compression.enabled` מוגדר `true`
2. בדקו שמספר האסימונים חורג מהסף
3. ודאו שיש מספיק הודעות בשיחה לדחיסה
4. עברו על יומני הדימון לאיתור שגיאות דחיסה

### איכות סיכום ירודה

1. נסו מודל סיכום אחר (למשל claude-3-sonnet)
2. הגדילו את `preserve_recent_messages` כדי לשמר יותר הקשר
3. הגדילו את `target_tokens` כדי לאפשר סיכומים ארוכים יותר
4. בדקו שמודל הסיכום זמין ופועל

### עלייה בהשהיה

1. הדחיסה מוסיפה קריאת API אחת (הסיכום)
2. השתמשו במודל סיכום מהיר יותר (Haiku הוא המהיר ביותר)
3. העלו את הסף כדי לדחוס לעיתים רחוקות יותר
4. שקלו לכבות את הדחיסה ביישומים רגישים להשהיה

### עלויות בלתי צפויות

1. עקבו אחרי עלות הסיכום בלוח השימוש
2. השוו בין החיסכון לעלות הסיכום
3. העלו את הסף כדי לדחוס לעיתים רחוקות יותר
4. השתמשו במודל הזול ביותר שזמין לסיכום

## השפעה על הביצועים

- **הערכת אסימונים** — כמילישנייה אחת לבקשה (זניח)
- **סיכום** — 1–3 שניות (תלוי במודל ובמספר ההודעות)
- **תקורת זיכרון** — מזערית (כ-1KB לכל דחיסה)
- **חיסכון בעלות** — בדרך כלל הפחתה של 30%–50% באסימונים

## הגדרות מתקדמות

### הנחיית סיכום מותאמת

```json
{
  "compression": {
    "enabled": true,
    "custom_prompt": "Create a technical summary of the following conversation, focusing on code changes, decisions, and action items:\n\n{messages}\n\nSummary:"
  }

```

### דחיסה מותנית

הפעילו דחיסה רק בתרחישים מסוימים:

```json
{
  "profiles": {
    "default": {
      "scenarios": {
        "longContext": {
          "providers": ["anthropic"],
          "compression": {
            "enabled": true,
            "threshold_tokens": 100000
          }
        },
        "default": {
          "providers": ["anthropic"],
          "compression": {
            "enabled": false
          }
        }
      }
    }
  }
}
```

### דחיסה רב-שלבית

דחסו כמה פעמים בשיחות ארוכות במיוחד:

```json
{
  "compression": {
    "enabled": true,
    "stages": [
      {
        "threshold_tokens": 50000,
        "target_tokens": 30000
      },
      {
        "threshold_tokens": 80000,
        "target_tokens": 40000
      }
    ]
  }
}
```
