# סנכרון תצורה

סנכרנו ספקים, פרופילים, פרופיל ברירת מחדל ולקוח ברירת מחדל בין מכשירים. אסימוני האימות מוצפנים ב-AES-256-GCM (גזירת מפתח בעזרת PBKDF2-SHA256) לפני ההעלאה.

## שירותים נתמכים

| שירות | תיאור |
|-------|-------|
| `webdav` | כל שרת WebDAV (למשל Nextcloud, ownCloud) |
| `s3` | ‏AWS S3 או אחסון תואם S3 (למשל MinIO, Cloudflare R2) |
| `gist` | ‏gist פרטי (דורש PAT עם הרשאת gist) |
| `repo` | קובץ במאגר דרך Contents API (דורש PAT עם הרשאת repo) |

## הגדרה

הגדירו את הסנכרון בעמוד ההגדרות של ממשק הווב:

```bash
# פתיחת הגדרות ממשק הווב
zen web  # הגדרות ← סנכרון תצורה
```

או משכו ידנית מה-CLI:

```bash
zen config sync
```

## דוגמת הגדרה

```json
{
  "sync": {
    "backend": "gist",
    "gist_id": "abc123def456",
    "token": "ghp_xxxxxxxxxxxx",
    "passphrase": "my-secret-passphrase",
    "auto_pull": true,
    "pull_interval": 300
  }
}
```

## הצפנה

כשמוגדרת סיסמת הצפנה, כל אסימוני האימות בנתוני הסנכרון מוצפנים ב-AES-256-GCM עם מפתח שנגזר ב-PBKDF2-SHA256‏ (600,000 איטרציות). המלח נשמר לצד הנתונים. ללא סיסמת הצפנה הנתונים מועלים כ-JSON גלוי.

## יישוב התנגשויות

- מיזוג לפי חותמת זמן לכל ישות: השינוי החדש יותר מנצח
- ישויות שנמחקו מסומנות במצבות (פגות אחרי 30 יום)
- ערכים סקלריים (פרופיל/לקוח ברירת מחדל): החותמת החדשה יותר מנצחת

## היקף הסנכרון

**מסונכרן:** ספקים (עם אסימונים מוצפנים), פרופילים, פרופיל ברירת המחדל, לקוח ברירת המחדל

**לא מסונכרן:** הגדרות פורטים, סיסמת ממשק הווב, קישורי פרויקטים, והגדרות הסנכרון עצמן
