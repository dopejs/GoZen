# תחילת עבודה

## התקנה

התקנה בשורה אחת:

```bash
curl -fsSL https://raw.githubusercontent.com/dopejs/gozen/main/install.sh | sh
```

הסרה:

```bash
curl -fsSL https://raw.githubusercontent.com/dopejs/gozen/main/uninstall.sh | sh
```

## הרצה ראשונה

הוסיפו את הספק הראשון:

```bash
zen config add provider
```

הפעלה עם פרופיל ברירת המחדל:

```bash
zen
```

הפעלה עם פרופיל מסוים:

```bash
zen -p work
```

הפעלה עם כלי CLI מסוים:

```bash
zen --cli codex
```
