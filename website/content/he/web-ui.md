# ממשק ווב

נהלו את כל ההגדרות באופן חזותי מהדפדפן. הדימון עולה אוטומטית כשצריך.

## שימוש

```bash
# פתיחה בדפדפן (מפעיל את הדימון במידת הצורך)
zen web
```

## יכולות

- ניהול ספקים ופרופילים
- ניהול קישורי פרויקטים
- הגדרות גלובליות (לקוח ברירת מחדל, פרופיל ברירת מחדל, פורטים)
- הגדרות סנכרון תצורה
- מציג יומני בקשות עם רענון אוטומטי
- השלמה אוטומטית לשדה המודל

## אבטחה

בהפעלה הראשונה של הדימון נוצרת אוטומטית סיסמת גישה. בקשות שאינן מקומיות (מחוץ ל-127.0.0.1/::1) מחייבות התחברות.

- אימות מבוסס סשן עם תפוגה שניתנת להגדרה
- הגנה מפני ניחוש כוחני עם השהיה מצטברת
- הצפנת RSA להעברת אסימונים רגישים (מפתחות API מוצפנים בדפדפן)
- גישה מקומית (127.0.0.1) עוקפת את האימות

### ניהול סיסמה

```bash
# איפוס סיסמת ממשק הווב
zen config reset-password

# שינוי הסיסמה מתוך ממשק הווב
zen web  # הגדרות ← שינוי סיסמה
```
