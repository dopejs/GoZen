# Агенты

GoZen может работать как операционный слой для агентов вроде Claude Code, Codex и других ассистентов из командной строки. Он помогает координировать их работу, наблюдать за сессиями и применять ограничения во время выполнения, не меняя привычный процесс.

## Что добавляет GoZen

- **Координация**: меньше конфликтов, когда над проектом работают несколько агентов.
- **Наблюдаемость**: сессии, расходы, ошибки и активность в одном месте.
- **Ограничения**: лимиты на расходы, частоту запросов и рискованные действия.
- **Маршрутизация задач**: разные задачи — разным провайдерам или профилям.

## Пример конфигурации

```json
{
  "agent": {
    "enabled": true,
    "coordinator": {
      "enabled": true,
      "lock_timeout_sec": 300,
      "inject_warnings": true
    },
    "observatory": {
      "enabled": true,
      "stuck_threshold": 5,
      "idle_timeout_min": 30
    },
    "guardrails": {
      "enabled": true,
      "session_spending_cap": 5.0,
      "request_rate_limit": 30
    }
  }
}
```

## Типичные сценарии

### Координация нескольких агентов

Когда в одном репозитории работают несколько агентов, GoZen отслеживает активность по файлам, показывает предупреждения и помогает избегать столкновений.

### Наблюдение за сессиями

Через панель и API можно смотреть активные сессии, расход токенов, количество ошибок и длительность работы.

### Применение ограничений

Ограничения могут приостановить вышедшую из-под контроля сессию, отметить рискованные операции и замедлить циклы повторов, пока они не стали дорогими.
