# Привязка проектов

Привязывайте каталоги к конкретным профилям и (или) CLI, чтобы настройки уровня проекта применялись автоматически.

## Использование

```bash
cd ~/work/company-project

# Привязать профиль
zen bind work-profile

# Привязать CLI
zen bind --cli codex

# Привязать и то, и другое
zen bind work-profile --cli codex

# Проверить состояние
zen status

# Отвязать
zen unbind
```

## Приоритет

Аргументы CLI > привязки проекта > глобальные значения по умолчанию
