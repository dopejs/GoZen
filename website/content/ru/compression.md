# Сжатие контекста (БЕТА)

:::warning Функция в стадии БЕТА
Сжатие контекста находится в бете. По умолчанию оно выключено и требует явной настройки.
:::

Автоматически сжимает контекст беседы, когда число токенов превышает порог: это снижает расходы, сохраняя качество разговора.

## Возможности

- **Автоматическое сжатие** — срабатывает при превышении порога токенов
- **Умное резюмирование** — дешёвая модель (claude-3-haiku) сжимает старые сообщения
- **Сохранение свежих сообщений** — последние сообщения остаются нетронутыми ради связности
- **Оценка токенов** — точный подсчёт перед вызовами API
- **Статистика** — видно, насколько эффективно работает сжатие
- **Прозрачная работа** — совместимо со всеми клиентами ИИ

## Как это работает

1. **Оценка токенов** — подсчёт токенов в истории беседы
2. **Проверка порога** — сравнение с заданным порогом (по умолчанию: 50 000)
3. **Выбор сообщений** — определение старых сообщений для сжатия
4. **Резюмирование** — краткое резюме дешёвой моделью
5. **Замена контекста** — старые сообщения заменяются резюме
6. **Передача запроса** — сжатый контекст уходит целевой модели

## Настройка

### Включение сжатия

```json
{
  "compression": {
    "enabled": true,
    "threshold_tokens": 50000,
    "target_tokens": 20000,
    "summarizer_model": "claude-3-haiku-20240307",
    "preserve_recent_messages": 5,
    "tokens_per_char": 0.25
  }
}
```

**Параметры:**

| Параметр | По умолчанию | Описание |
|--------|---------|-------------|
| `enabled` | `false` | Включает сжатие контекста |
| `threshold_tokens` | `50000` | Запускает сжатие при превышении этого значения |
| `target_tokens` | `20000` | Целевое число токенов после сжатия |
| `summarizer_model` | `claude-3-haiku-20240307` | Модель для резюмирования |
| `preserve_recent_messages` | `5` | Сколько свежих сообщений оставить нетронутыми |
| `tokens_per_char` | `0.25` | Коэффициент оценки при подсчёте токенов |

### Настройка для профиля

Включите сжатие для отдельных профилей:

```json
{
  "profiles": {
    "long-context": {
      "providers": ["anthropic"],
      "compression": {
        "enabled": true,
        "threshold_tokens": 100000,
        "target_tokens": 40000
      }
    },
    "short-context": {
      "providers": ["openai"],
      "compression": {
        "enabled": false
      }
    }
  }
}
```

## Оценка токенов

GoZen быстро оценивает токены по числу символов:

```
estimated_tokens = character_count * tokens_per_char
```

**Коэффициент по умолчанию:** 0,25 токена на символ (1 токен ≈ 4 символа)

**Точность:** ±10 % для английского текста, для других языков может отличаться

Для точного подсчёта GoZen использует библиотеку `tiktoken-go`, когда она доступна.

## Стратегия сжатия

### Выбор сообщений

1. **Системные сообщения** — сохраняются всегда
2. **Свежие сообщения** — последние N сообщений сохраняются (по умолчанию: 5)
3. **Более старые сообщения** — кандидаты на сжатие

### Промпт для резюмирования

```
Summarize the following conversation history concisely while preserving key information, decisions, and context:

[older messages]

Provide a brief summary that captures the essential points.
```

### Результат

```
Original: 45,000 tokens (30 messages)
After compression: 22,000 tokens (summary + 5 recent messages)
Savings: 23,000 tokens (51%)
```

## Веб-интерфейс

Настройки сжатия находятся по адресу `http://localhost:19840/settings`:

1. Откройте вкладку «Compression» (помечена значком BETA)
2. Включите «Enable Compression»
3. Настройте порог и целевое число токенов
4. Выберите модель для резюмирования
5. Задайте число свежих сообщений, которые нужно сохранить
6. Нажмите «Save»

### Панель статистики

Смотрите статистику сжатия:

- **Всего сжатий** — сколько раз срабатывало сжатие
- **Сэкономлено токенов** — суммарная экономия
- **Средняя экономия** — среднее сокращение на одно сжатие
- **Доля сжатий** — процент запросов, вызвавших сжатие

## Точки API

### Получить статистику сжатия

```bash
GET /api/v1/compression/stats
```

Ответ:
```json
{
  "enabled": true,
  "total_compressions": 42,
  "tokens_saved": 1250000,
  "average_savings": 29761,
  "compression_rate": 0.15,
  "last_compression": "2026-03-05T10:30:00Z"
}
```

### Обновить настройки сжатия

```bash
PUT /api/v1/compression/settings
Content-Type: application/json

{
  "enabled": true,
  "threshold_tokens": 60000,
  "target_tokens": 25000
}
```

### Сбросить статистику

```bash
POST /api/v1/compression/stats/reset
```

## Сценарии использования

### Долгие сессии программирования

**Сценарий:** многочасовая работа с Claude Code

**Конфигурация:**

```json
  "compression": {
    "enabled": true,
    "threshold_tokens": 80000,
    "target_tokens": 30000,
```

**Польза:** сохранить связность беседы, не упираясь в лимит контекста

### Пакетная обработка

**Сценарий:** обработка множества документов с помощью ИИ

**Конфигурация:**
```json
{
  "compression": {
    "enabled": true,
    "threshold_tokens": 40000,
    "target_tokens": 15000,
    "preserve_recent_messages": 3
  }
}
```

**Польза:** снизить расходы при работе с большими наборами документов

### Исследования и анализ

**Сценарий:**длинные исследовательские сессии по нескольким темам

```json
  }

```

**Польза:** держать фокус на свежих темах, сохраняя более ранний контекст

## Рекомендации

1. **Начните со значений по умолчанию** — они подходят для большинства случаев
2. **Следите за статистикой** — регулярно проверяйте долю сжатий и экономию
3. **Подберите порог** — выше для моделей с длинным контекстом (Claude Opus), ниже для коротких
4. **Оставляйте достаточно сообщений** — 5–10 свежих сообщений ради связности
5. **Берите дешёвую модель для резюме** — Haiku быстрая и экономичная
6. **Проверьте до продакшена** — оцените качество на своём сценарии

## Ограничения

1. **Потеря качества** — резюме может терять нюансы
2. **Рост задержки** — добавляется вызов API для резюмирования
3. **Компромисс по стоимости** — расходы на резюме против сэкономленных токенов
4. **Поддержка языков** — лучше всего работает с английским, для других языков возможны отличия
5. **Окно контекста** — превысить максимальное окно модели нельзя

## Устранение неполадок

### Сжатие не срабатывает

1. Убедитесь, что `compression.enabled` равно `true`
2. Проверьте, что число токенов превышает порог
3. Убедитесь, что в беседе достаточно сообщений для сжатия
4. Изучите журналы демона на предмет ошибок сжатия

### Плохое качество резюме

1. Попробуйте другую модель (например, claude-3-sonnet)
2. Увеличьте `preserve_recent_messages`, чтобы сохранить больше контекста
3. Поднимите `target_tokens`, чтобы разрешить более длинные резюме
4. Проверьте, доступна ли модель резюмирования и работает ли она

### Выросла задержка

1. Сжатие добавляет один вызов API (резюмирование)
2. Возьмите более быструю модель (Haiku самая быстрая)
3. Поднимите порог, чтобы сжимать реже
4. Для задач, чувствительных к задержке, сжатие лучше выключить

### Неожиданные расходы

1. Следите за стоимостью резюмирования в панели использования
2. Сравнивайте экономию со стоимостью резюме
3. Поднимите порог, чтобы сжимать реже
4. Используйте самую дешёвую доступную модель для резюмирования

## Влияние на производительность

- **Оценка токенов** — около 1 мс на запрос (пренебрежимо)
- **Резюмирование** — 1–3 секунды (зависит от модели и числа сообщений)
- **Расход памяти** — минимальный (около 1 КБ на сжатие)
- **Экономия** — обычно на 30–50 % меньше токенов

## Расширенная настройка

### Свой промпт для резюмирования

```json
{
  "compression": {
    "enabled": true,
    "custom_prompt": "Create a technical summary of the following conversation, focusing on code changes, decisions, and action items:\n\n{messages}\n\nSummary:"
  }
}
```

### Условное сжатие

Включайте сжатие только для определённых сценариев:

```json
{
  "profiles": {
    "default": {
      "scenarios": {
        "longContext": {
          "providers": ["anthropic"],
          "compression": {
            "enabled": true,
            "threshold_tokens": 100000
          }
        },
        "default": {
          "providers": ["anthropic"],
          "compression": {
            "enabled": false
          }
        }
      }
    }
  }
}
```

### Многоступенчатое сжатие

Сжимайте несколько раз для очень длинных бесед:

```json
{
  "compression": {
    "enabled": true,
    "stages": [
      {
        "threshold_tokens": 50000,
        "target_tokens": 30000
      },
      {
        "threshold_tokens": 80000,
        "target_tokens": 40000
      }
    ]
  }
}
```
