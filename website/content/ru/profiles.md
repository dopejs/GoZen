# Профили и переключение

Профиль — это упорядоченный список провайдеров для отказоустойчивости. Если первый провайдер недоступен, происходит автоматический переход к следующему.

## Пример конфигурации

```json
{
  "profiles": {
    "default": {
      "providers": ["anthropic-main", "anthropic-backup"]
    },
    "work": {
      "providers": ["company-api"],
      "routing": {
        "think": {"providers": [{"name": "thinking-api"}]}
      }
    }
  }
}
```

## Использование профилей

```bash
# Профиль по умолчанию
zen

# Указанный профиль
zen -p work

# Интерактивный выбор
zen -p
```
