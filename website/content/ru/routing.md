# Маршрутизация по сценариям

Запросы автоматически направляются разным провайдерам в зависимости от их характеристик.

## Поддерживаемые сценарии

| Сценарий | Описание |
|----------|----------|
| `think` | Включён режим размышления |
| `image` | Содержит изображение |
| `longContext` | Объём превышает порог |
| `webSearch` | Используется инструмент web_search |
| `background` | Используется модель Haiku |

## Механизм отката

Если все провайдеры сценария недоступны, маршрутизация автоматически откатывается к провайдерам профиля по умолчанию.

## Пример конфигурации

```json
{
  "profiles": {
    "smart": {
      "providers": ["main-api"],
      "long_context_threshold": 60000,
      "routing": {
        "think": {
          "providers": [{"name": "thinking-api", "model": "claude-opus-4-5"}]
        },
        "longContext": {
          "providers": [{"name": "long-context-api"}]
        }
      }
    }
  }
}
```
