# Веб-интерфейс

Управляйте всеми настройками визуально в браузере. Демон запускается автоматически, когда это нужно.

## Использование

```bash
# Открыть в браузере (при необходимости запустит демон)
zen web
```

## Возможности

- Управление провайдерами и профилями
- Управление привязками проектов
- Глобальные настройки (клиент по умолчанию, профиль по умолчанию, порты)
- Настройки синхронизации конфигурации
- Просмотр журнала запросов с автообновлением
- Автодополнение поля модели

## Безопасность

При первом запуске демон автоматически создаёт пароль доступа. Для нелокальных запросов (вне 127.0.0.1/::1) требуется вход.

- Сессионная аутентификация с настраиваемым сроком действия
- Защита от перебора с экспоненциальной задержкой
- RSA-шифрование при передаче чувствительных токенов (ключи API шифруются в браузере)
- Локальные обращения (127.0.0.1) обходят аутентификацию

### Управление паролем

```bash
# Сбросить пароль веб-интерфейса
zen config reset-password

# Сменить пароль в веб-интерфейсе
zen web  # Настройки → Смена пароля
```
